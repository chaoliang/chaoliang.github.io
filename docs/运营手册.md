# DateTally 上线与赚钱运营手册

这个站点的商业模式：**Google 搜索流量 + AdSense 广告**。你不需要卖任何东西、不需要粉丝、不需要客服。流量由 Google 送上门，广告由 Google 卖，你只需要把站点挂在网上并保持每日自动更新（CI 已配好）。

**先说实话（预期管理）：**
- SEO 是慢生意：通常 1–2 个月开始有零星流量，3–6 个月爬坡。
- 同类日期计算站成熟后月流量 5 万–50 万 PV；按 AdSense RPM $1–5 估算，对应 **月收入约 $50–$2500**。
- 不保证结果。但边际成本≈0（只有域名钱），值得挂着长期跑。

---

## 第一步：买域名（唯一必要开销，约 $10/年）

1. 到 Cloudflare Registrar、Namecheap 或 Porkbun 搜索可用域名。
2. 推荐关键词相关、好记的 .com：`datetally.com`（首选，如可用）、`daytally.com`、`datecount.io` 等。
3. 买好后，把 `site.config.json` 里的 `siteUrl` 改成你的域名，重新 build 即可。

> ⚠️ 不要用免费的 `xxx.github.io` 子域名收广告——AdSense 不给共享子域名过审。域名是必需投资。

## 第二步：部署到 GitHub Pages（免费托管 + 每日自动更新）

```bash
cd /Users/liliang/claude/makemoney
gh repo create datetally --private --source . --push   # 或在网页上建仓库后 git push
```

1. GitHub 仓库 → **Settings → Pages** → Source 选 **GitHub Actions**。
2. 推送后 `.github/workflows/deploy.yml` 会自动：跑测试 → 构建 503 页 → 部署。
3. 同页面绑定自定义域名（填你买的域名），按提示在域名商处加 DNS 记录（CNAME 指向 `<你的用户名>.github.io`），勾选 Enforce HTTPS。
4. workflow 里已配置**每天 00:10 UTC 自动重建**，保证"今天+N天"的数字永远新鲜（页面 JS 也会实时校正，双保险）。

## 第三步：提交 Google 收录（上线当天做）

1. 打开 [Google Search Console](https://search.google.com/search-console)，添加你的域名资源（DNS 验证）。
2. 提交 sitemap：`https://你的域名/sitemap.xml`（503 个 URL 会逐步被收录，2–4 周正常）。
3. 顺手在 [Bing Webmaster Tools](https://www.bing.com/webmasters) 也提交一次（可直接从 GSC 导入）。

## 第四步：申请 AdSense（建议上线 3–4 周、有基础收录后申请）

1. 到 [adsense.google.com](https://adsense.google.com) 注册，添加你的域名。
2. 按提示把验证代码加进去：最简单的方式是把你的发布商 ID（`ca-pub-xxxx`）填进 `site.config.json` 的 `adsensePublisherId`，然后 push——构建脚本会自动在每页 `<head>` 注入 AdSense 脚本并生成 `ads.txt`。
3. 等待审核（几天到两周）。过审后广告自动开始展示（广告位已内置在每个页面正文中，占位容器有固定高度，不会导致布局跳动）。
4. 收款：AdSense 满 $100 起付，支持**电汇到中国大陆银行账户**（后台填银行的 SWIFT 码即可，招行/工行等都支持）。

**过审要点（本站已内置）：** ✅ 原创长文（5 篇 guides）✅ 隐私政策/条款/关于/联系页 ✅ 无版权问题 ✅ HTTPS ✅ 移动端适配。若首次被拒（常见原因"内容质量"），隔 2 周补 2–3 篇 guides 再申请。

## 第五步：日常运营（每月 1–2 小时）

- **看数据**：Search Console → 效果报告，看哪些词有展现。哪个词族有流量，就往那个方向加页面。
- **加内容**：让 Claude Code 继续加页面族，优先级：
  1. `N weeks from today` / `N months from today`（复用现有架构，一小时的活）
  2. 更多 guides 文章（每篇都是长期资产）
  3. 西班牙语版本（同样的关键词，竞争小一半）
- **别碰的坑**：不要买外链、不要堆砌关键词、不要复制别人内容——会被 Google 惩罚，前功尽弃。

## 收入增长路线

| 阶段 | 信号 | 动作 |
|------|------|------|
| 0–1 月 | 收录中 | 什么都不用做，等 |
| 1–3 月 | 每天几十个点击 | 申请/接入 AdSense |
| 3–6 月 | 月 1 万+ PV | 加页面族、加语言版本 |
| 6 月+ | 月 5 万+ PV | 考虑换 Ezoic/Mediavine 类广告平台（RPM 高 2–3 倍）；复制整套模式做第二个站 |
